CENTRO DE AYUDA

Un flujo claro. De principio a fin.

Diseñado para asistir al equipo de análisis de crédito.

01

Recopila y confirma

Crea una solicitud o extrae campos de un PDF. Confirma siempre la información detectada. Los documentos se procesan en memoria y no se almacenan.

02

Analiza con contexto

La política calcula capacidad con ingreso, deuda, plazo y tasa. El índice interno de 0 a 100 es orientativo; no es un score de buró ni una probabilidad de impago.

03

Decide y deja evidencia

El analista prepara el caso. El administrador registra la decisión y su motivo. Cada cambio queda en la bitácora; una carga documental nueva reabre la revisión.

IA con una función concreta

El copiloto genera resúmenes, listas de verificación y borradores para el cliente. Si OpenAI no está configurado o no responde, utiliza un resumen local claramente identificado. No se envían nombres, RFC, CURP, domicilios ni texto de documentos al proveedor.

Configurar tu espacio

Define APP_PASSWORD para el usuario admin y opcionalmente ANALYST_PASSWORD para analyst. Activa el copiloto con OPENAI_API_KEY y el modelo con OPENAI_MODEL. En Render, usa PostgreSQL mediante DATABASE_URL para conservar expedientes entre despliegues.

Este espacio corresponde a una sola organización. Antes de operar con datos reales, configura credenciales individuales mediante tu proveedor de identidad, respaldos y la política de crédito aprobada por tu empresa.
